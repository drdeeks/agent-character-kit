# Terms — hosted ChatGPT ACK

Software license: MIT (`LICENSE`).

Hosted ACK does not evaluate constitution on the ChatGPT client. Policy
runs in the Worker using the same `evaluatePolicy` engine as the local
daemon. Unreachable storage is `unavailable`, not allow, when the profile
is fail-closed.

Use at your own risk. ACK is a reminder and deterrent, not a warranty.
